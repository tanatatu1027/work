# センター薬局 ウェブサイト（リニューアル）

愛媛県松山市会津町「センター薬局」のリニューアル版ウェブサイトです。
[清水整形外科クリニック](https://www.shimizuseikei-clinic.com/) や
[es-elio](https://es-elio.com/) のような、清潔感のあるモダンな医療系サイトを参考に、
**1ページ完結（ランディングページ型）／レスポンシブ／高速** な構成で作り直しました。

ビルド不要の **静的サイト（HTML / CSS / JS のみ）** なので、どのサーバーにもそのまま置けます。

## 構成

```
website/
├── index.html          … 本体（全セクション）
├── css/style.css       … デザイン
├── js/main.js          … ナビ開閉・スクロール演出・地図など
└── assets/favicon.svg  … ファビコン（ロゴ）
```

## ページ内のセクション

1. **ヒーロー** … キャッチコピー＋受付時間カード＋電話/アクセスボタン
2. **お知らせ** … 体制・在宅などのトピック
3. **ごあいさつ** … 薬局紹介と管理薬剤師あいさつ
4. **取り組み（サービス）** … 調剤・在宅・一包化・オンライン資格確認/電子処方箋・医療DX・かかりつけ
5. **在宅対応** … ご自宅へお薬をお届けする案内
6. **営業時間** … 曜日別の受付時間表＋時間外緊急連絡先
7. **アクセス** … 薬局情報＋Googleマップ
8. **フッター** … 住所・電話・メニュー

## 写真・画像の差し替え方法

現状はネットワーク制限のため元サイトの写真を取得できず、**SVGイラスト**で代用しています。
実際の薬局外観・スタッフ・店内写真があれば、より「人に見てもらえる」印象になります。

差し替えたい箇所：

- **ごあいさつのビジュアル**（`index.html` の `.about-photo` 内の `<svg>`）
  → 写真に置き換える場合は次のように変更します。
  ```html
  <div class="about-photo">
    <img src="assets/shop.jpg" alt="センター薬局の店内" />
  </div>
  ```
- **ヒーロー背景** … `css/style.css` の `.hero-bg` を写真にしたい場合：
  ```css
  .hero-bg { background: url("../assets/hero.jpg") center/cover; }
  ```
  （文字が読みやすいよう、上に半透明の白を重ねるのがおすすめです）

画像は `website/assets/` に入れてください。

## ローカルでの確認

特別なツールは不要です。`index.html` をブラウザで開くだけで表示できます。
（Googleマップを正しく読み込むには、簡易サーバー経由が確実です）

```bash
cd website
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 公開（デプロイ）

`website/` の中身をそのままアップロードするだけです。

- レンタルサーバー … FTPで `website/` の中身を公開ディレクトリへ
- GitHub Pages / Netlify / Vercel … 公開ディレクトリ（ルート）を `website` に指定

## カスタマイズの勘どころ

- **色** … `css/style.css` 冒頭の `:root` 変数（`--green` などを変えると全体の色が変わります）
- **文言** … すべて `index.html` 内のテキストを直接編集
- **お知らせ** … `index.html` の `<ul class="news-list">` に `<li>` を増やすだけ
