# センター薬局 ウェブサイト（リニューアル）

愛媛県松山市会津町「センター薬局」のリニューアル版ウェブサイトです。
[清水整形外科クリニック](https://www.shimizuseikei-clinic.com/) や
[es-elio](https://es-elio.com/) のような、清潔感のあるモダンな医療系サイトを参考に、
**1ページ完結（ランディングページ型）／レスポンシブ／高速** な構成で作り直しました。

ビルド不要の **静的サイト（HTML / CSS / JS のみ）** なので、どのサーバーにもそのまま置けます。

## 構成

```
website/
├── index.html          … 本体（全セクション）
├── css/style.css       … デザイン
├── js/main.js          … ナビ開閉・スクロール演出・地図など
└── assets/favicon.svg  … ファビコン（ロゴ）
```

## ページ内のセクション

1. **ヒーロー** … 店舗外観の実写＋キャッチコピー＋受付時間カード＋電話/アクセスボタン
2. **特長（FEATURES）** … どちらの処方箋でも受付／在宅医療／キャッシュレス決済（実アイコン使用）
3. **対応体制バッジ** … 基準薬局・マイナ保険証・電子処方箋・医療DX 等
4. **お支払い（PAYMENT）** … 対応キャッシュレス決済の一覧
5. **在宅医療（HOME CARE）** … ご自宅へお薬をお届けする案内
6. **お知らせ（NEWS）** … 医療DX加算・ホームページ開設のお知らせ
7. **営業時間（HOURS）** … 曜日別の受付時間表＋時間外緊急連絡先
8. **アクセス（ACCESS）** … 薬局情報＋Googleマップ
9. **お問い合わせ帯・フッター** … 電話・住所・メニュー

### 画像の差し替え方法

別の写真に変えたい場合は、`assets/img/` の同名ファイルを置き換えるだけです。
例：店内写真をヒーローに使いたい → `assets/img/hero.jpg` を差し替え。
（ヒーローは上に濃いグラデーションを重ねて文字を読みやすくしています。
明るすぎる／暗すぎる写真のときは `css/style.css` の `.hero-overlay` の濃さを調整してください）

> `standalone.html` は画像を **Base64で埋め込んだ1ファイル版** です。画像を差し替えたら、
> 下記コマンドで作り直せます（このリポジトリの生成手順に準拠）。

## ローカルでの確認

特別なツールは不要です。`index.html` をブラウザで開くだけで表示できます。
（Googleマップを正しく読み込むには、簡易サーバー経由が確実です）

```bash
cd website
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 公開（デプロイ）

`website/` の中身をそのままアップロードするだけです。

- レンタルサーバー … FTPで `website/` の中身を公開ディレクトリへ
- GitHub Pages / Netlify / Vercel … 公開ディレクトリ（ルート）を `website` に指定

## カスタマイズの勘どころ

- **色** … `css/style.css` 冒頭の `:root` 変数（`--green` などを変えると全体の色が変わります）
- **文言** … すべて `index.html` 内のテキストを直接編集
- **お知らせ** … `index.html` の `<ul class="news-list">` に `<li>` を増やすだけ
